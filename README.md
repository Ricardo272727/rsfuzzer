# rsfuzzer

Repositorio de trabajo para desarrollar un fuzzer de logica de negocio/autorizacion para APIs e integrarlo con mitmproxy.

## Quick start

```powershell
cd rsfuzzer
uv run rsfuzzer --help
```

## Comandos iniciales

- `rsfuzzer discover`
- `rsfuzzer test`
- `rsfuzzer report`

## Estructura

- `src/rsfuzzer/`: codigo del paquete
- `tests/`: pruebas
